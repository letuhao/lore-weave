# CLAUDE.md

**The development guide for this repository lives in [`AGENTS.md`](AGENTS.md). Read that file.**

This file exists only so that tools looking for `CLAUDE.md` by name find their way there. It is a
pointer, deliberately kept empty of rules: guidance that is duplicated goes stale in one copy and
then actively misleads. **One home, one name.**
