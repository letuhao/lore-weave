## Original Request

## Settings
- Testing: yes — regression testing against a scratch stack IS this plan's core content, not an add-on
- Logging: standard — most tasks are verification/process steps against existing services, not new instrumented code; where a bug fix touches code, follow that file's existing log-level convention (this repo already logs heavily at INFO/DEBUG throughout)
- Docs: yes, mandatory — Phase 5 ends in a real reviewed runbook + a finalized `CHANGELOG.md [0.1.0]` section, not optional

## Branch discipline (from the user directly — binding for every phase below)
**A bug fix must never exist ONLY on `release/v0.1.0`.** Every fix found during go-live testing is
fixed and merged to `main` (fix-on-main-then-merge-into-release, or fix-on-release-then-immediately
merge-to-main — either order, same outcome required), so `release/v0.1.0` never drifts into a fork
holding un-merged fixes. The final `v0.1.0` tag is cut from `main` once `release/v0.1.0` is clean and
fully merged back — not from the release branch directly.

## Roadmap Linkage
Milestone: "none"
Rationale: No `.ai-factory/ROADMAP.md` exists in this repo; the authoritative planning corpus is
`docs/plans/` per this repo's own `aif-plan` skill-context override.
