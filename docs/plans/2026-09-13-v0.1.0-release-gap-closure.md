## Why this plan exists

The remediation branch was verified almost entirely at the UNIT level. That is the wrong shape of
evidence for what it changed. The defects it fixed were found by a browser driving a running stack,
and the largest single change in it — ten new strings across eighteen locales — is 197 pieces of
user-facing text that **no person has read**.

The release bar is unchanged and is D1 from the previous plan: *every README claim must be true of
the build, or removed.* A unit test cannot establish that. A user journey can.

  0
