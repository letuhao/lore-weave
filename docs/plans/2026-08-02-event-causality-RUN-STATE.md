## 1. What this round is

Design the **event layer**: the middle layer that orchestrates causality across the whole game — what
happens, what it causes, and what is written down.

The PO's framing, verbatim in meaning: *a very important middle layer that coordinates all cause-and-effect
in the game, writes data to the DB, and triggers events plus the chains of consequent events for every
feature.*

**The two questions this round exists to answer:**

| | |
|---|---|
| **Q-A** | **What IS an event?** Where does the line fall between a submitted intent · a rule-engine fact · a threshold crossing · a status application · a world occurrence (a siege, a festival, a tribulation) · a scheduled fiction-time firing · a durable record appended to a log? Are these one concept or several sharing a word? |
| **Q-B** | **What do we STORE?** Which of the above become durable records · which are transient in-tick signals · which are derived and must NEVER be stored. |

Everything else — transport, the reaction *vocabulary*, per-feature event content — is downstream of
these two and is not this round's deliverable.
