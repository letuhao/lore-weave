# LoreWeave project context — applies to EVERY aif-* skill

This file is read before any AI Factory skill runs. It exists so that a contributor
using Codex, Copilot or Claude Code follows **one** process on this repository.

## Precedence — settle this before anything else

1. **[`AGENTS.md`](../../../AGENTS.md) is authoritative.** It holds the LOCKED invariants and the
   12-phase task workflow. AI Factory is a **runner**, not a rulebook: it decides *how*
   an agent moves through work, never *what this project permits*.
2. **[`docs/standards/README.md`](../../../docs/standards/README.md) is the index** of every cross-cutting rule. It links out
   and never duplicates. Check it before assuming a rule does not exist.
3. **The mechanical gates outrank both.** `.githooks/pre-commit` and `scripts/*-gate.py`
   are scripts, not conventions. If a gate blocks you, fix the cause — never `--no-verify`.
4. Where an aif-* skill's general instruction conflicts with 1–3, **1–3 win**, and the
   deviation is a defect to report, not a judgement call to make.

## The invariants no skill may route around

These have each already cost this project a real incident; the full statements are in
`AGENTS.md`. An agent must not "helpfully" work around any of them:

- **Provider gateway** — no service imports a provider SDK or calls a provider API
  directly; everything goes through `provider-registry-service`. A local model backend
  is a BYOK credential, not a per-service URL/token env var.
- **No hardcoded model names or pricing** in runtime code.
- **MCP-first** for agentic logic — an MCP tool through `ai-gateway`, never a bespoke
  HTTP endpoint driven by a raw prompt.
- **Language rule** — `contracts/language-rule.yaml` decides a service's language.
- **User boundaries** — self-hosted is NOT single-user. Every user-facing table carries a
  scope key and every query filters by it. A regular user must never mutate a System-tier row.
- **Written artifacts are ENGLISH** — code, comments, docs, commits, PR bodies, test names.
  Chat with the human is whatever language they wrote in; the artifact is not the conversation.
- **Non-vacuity** — a check that cannot fail is worse than no check. Adding a gate, test or
  assertion means breaking the guarded thing, watching it go red, restoring it, and pasting
  the output as evidence. "I added a test" is not evidence.
- **Destructive DB ops in tests** — scope every cleanup, read the DSN only from a dedicated
  `*_TEST_*` var, and guard before you destroy.
- **Nothing machine-local goes in a tracked file** — no credentials, tokens, passwords, private
  keys, local endpoints, test-account details, database UUIDs, or `user_model_id`s. These are
  per-developer: pinned in a tracked file they send the next contributor to someone else's row,
  and a credential among them is a leak. Name the environment variable or the git-ignored file
  the value comes from instead.

## Orientation at the start of a task

Read `docs/sessions/SESSION_HANDOFF.md` (the **▶ NEXT SESSION** block) before proposing work,
and treat any Deferred row whose target phase is the current phase as a must-do.

## Personalising this

Do not edit this file to suit your own habits — it is shared. Put personal overrides in
`.ai-factory/skill-context.local/` (git-ignored). See
[`docs/standards/agent-workflow.md`](../../../docs/standards/agent-workflow.md).
